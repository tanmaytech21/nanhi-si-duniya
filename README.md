🧸 Nanhi Si Duniya

A website project for a creche and childcare service, built using HTML, CSS, JavaScript and Supabase.

🌐 Live Website

https://nanhi-si-duniya.netlify.app/

✨ Features

- 🏠 Home page for the creche
- 📝 Parent admission enquiry form
- 🔐 Parent signup and login interface
- 🛡️ Admin login and dashboard interface
- 🗄️ Supabase backend integration
- 🗺️ Sitemap for search engine discovery

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Netlify

🎯 Project Goal

The goal of this project is to create a simple online presence for a creche, help parents submit admission enquiries, and provide an interface for managing enquiries.
